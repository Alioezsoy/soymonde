# Archive photos

Put the photos for the archive in this folder. They appear on the
website automatically, in the order of their file names.

Name the files with a number in front, and one of the words
`process`, `sketch` or `studio` so the photo gets the right label:

    01-studio-desk.jpg
    02-sketch-hoodie.jpg
    03-process-cutting.jpg

Formats: .jpg, .jpeg, .png, .webp
